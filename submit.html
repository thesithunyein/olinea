What this is

Olinea is a personal post-quantum USDC vault on Arc mainnet. You back up 24 words, derive an SLH-DSA-SHA2-128s key in the browser, and only that key can authorize a release through Arc's post-quantum precompile. The deployed factory lets a user create their own vault in one transaction. The console is the part a reviewer can open and try without an account: create a key, prove it on Arc mainnet, then create a vault.

About the link

The console reads the factory address from the URL, so the same app can be pointed at any deployed factory. This page is the canonical submission link for the deployed factory: it opens the console already pointed at the live address.
