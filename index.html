The line that decides everything

A malformed call reverts, but a cryptographically invalid signature returns false without reverting. A contract that checks only “did the call succeed” accepts every forged signature on earth: 

// WRONG — true for every forgery
(bool ok, ) = PRECOMPILE.staticcall(data);
require(ok, "verify failed");

// CORRECT — the signature is a value, not an exception
(bool ok, bytes memory ret) = PRECOMPILE.staticcall(data);
require(ok && abi.decode(ret, (bool)), "invalid PQ signature");

How Olinea works

  1. Deposit USDC into the vault and register a 32-byte hash-based verifying key. No Arc account is needed to hold the key.
  2. Authorize a release in your browser: recipient, amount, nonce — signed with SLH-DSA. The chain, vault, recipient, amount and nonce are bound into the signed message, so signatures can't be replayed.
  3. Verify and send: anyone can relay the authorization. The vault asks the precompile, decodes the boolean, and only then transfers the USDC.

Why it matters before quantum computers arrive

Long-lived keys are already being harvested to be broken later. Meanwhile a 32-byte hash-based key, kept offline, cannot be forged even by a fully compromised hot wallet — so Olinea is useful today as a second authorization factor on a treasury, and necessary tomorrow for the same reason post-quantum standards exist at all.
